# Axis 1.25.2

Changes since Android 1.25.1:

- **MutaMarket in Variations.** Compare public abyssal listings alongside My Abyssals. Select multiple sources, narrow your collection by character or container, and use independent switches for auctions and multi-item contracts.
- **More useful comparisons.** Sort by attributes and derived stats, lock individual attributes to hide worse rolls, and filter for modules that fit. The abyssal price limit uses a clear millions-of-ISK field and leaves standard modules visible. Sorting changes the order; attribute locks control which rolls are hidden.
- **Clearer abyssal details.** Info sheets show ownership, location, custom names, source and contract-type badges, asking prices and labelled estimates. Save custom rolls to your collection and remove saved copies when no longer needed.
- **Contract shopping lists.** Copy a single EVE contract link or all links for a fit without linking a character. Open listings on MutaMarket or send a contract to a connected EVE client.
- **Honest fit values and offline handling.** Confirmed asking prices contribute to fit totals; unknown values are flagged. Saved modules and contract details remain accessible when the network is unavailable.
- **Fitting fixes.** Removing a mutaplasmid fully restores the stock module. Damage graphs now include external command-burst bonuses to scrambler range, and stealth-bomber launcher fitting indicators correctly apply hull reductions.
- **New abyssal launcher icon**, plus matching source badges and cleaner mobile controls.

Download `app-debug.apk` below to install or update the Android sideload build.
