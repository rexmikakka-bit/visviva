# What's New in Axis 1.25.17

Changes since iOS 1.25.14:

- Updated ship stats and trait descriptions for the EVE 24.01 balance changes.
- Search MutaMarket abyssal listings across all regions, with station names shown where available.
- Download all market prices in advance for offline fitting using the new "Download all prices" option in Market settings.
- Choose the time window used for cumulative damage and repair graphs. Zooming the range axis no longer changes those totals.
- Fixed damage-inflicted graphs against target speed and signature radius to show total damage rather than DPS.
- Selecting a standard module variant from a grouped weapon row now replaces the whole group. Individual abyssal rolls still replace only one module.
